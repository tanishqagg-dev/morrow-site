# Open proof points

1. Test bundled Codex realtime voice and account login in a signed customer build on each supported ChatGPT plan. Confirm commercial distribution rights before selling it.
2. Test five to eight nontechnical Mac users with a clickable prototype: start speaking, stop the mic, resume yesterday's task, find a finished file, correct a transcript, and manage billing without coaching. Revisit the no-history-navigation choice if recovery fails.
3. Measure actual speech latency, interruption, noisy-room use, mic changes, and caption accuracy. Competitor docs cannot prove Morrow performance.
4. Decide trial allowance and Morrow price after trial entitlement and payment return work. The current ₹3,499 preview is not a validated consumer price.
5. Verify signed installer, OpenAI sign-in, browser checkout, webhook, and automatic app unlock end to end.
6. Specify local retention, export, and deletion. Do not claim cross-device sync before it exists.
